Тип продукта Telegram Mini App + AI Agent
Midas — персональная финансовая операционная система, управляемая через
Telegram. AI-агент с адаптивным анализом входящих и исходящих финансовых
потоков. Интеграция с крипто-кошельками (TRC20 / BEP20 / ERC20), Google Sheets и
Notion. Полностью кастомизируемые категории расходов и доходов.
1. Общее описание проекта
Midas — AI-агент-бухгалтер внутри Telegram. Продукт состоит из двух частей:

Telegram-бот (чат) — приём данных текстом, уведомления и алерты.
Telegram Mini App — дашборд, графические отчёты, кастомизация категорий и
настроек.
Ключевой принцип: максимальная кастомизация. Пользователь может добавлять и
редактировать любые категории, подключать свои источники данных и настраивать
периодичность отчётов.

Два потока данных:
Входящий поток Транзакции с крипто-кошельков, данные из Google Sheets и Notion, ручной ввод в чат
Исходящий поток Аналитические отчёты, инфографика, алерты, записи в Notion и Google Sheets
2. Архитектура системы
Рекомендуемый технологический стек:
Компонент Технология / описание
AI-ядро Claude API (Anthropic) — понимание текста, анализ, генерация отчётов
Оркестрация Python (FastAPI + aiogram) или n8n для low-code варианта
Telegram Bot aiogram 3.x + Webhook
Mini App React / Vue — фронтенд внутри Telegram WebApp
База данных PostgreSQL — транзакции, категории, пользователи
Очередь задач Celery + Redis — периодические задачи мониторинга
Хостинг VPS + Docker Compose
Схема работы агента:
Пользователь вводит текст → Telegram Bot передаёт сообщение в Claude API → Claude
определяет намерение → Агент вызывает нужный инструмент (БД / Sheets / блокчейн)
→ Формирует ответ и отправляет в Telegram.

3. Структура категорий расходов
3.1 Бизнес-расходы
Категория Описание
Трафик Реклама, закупка трафика, продвижение
Пробные направления Тестовые бюджеты на новые проекты
Разработка Разработчики, дизайн, IT-инфраструктура
Каналы Telegram-каналы, YouTube, медиа
Техническое обслуживание Хостинг, серверы, SaaS-подписки
Серые направления ⚠ Отображается красным цветом во всех отчётах
▲ Строка «Серые направления» в интерфейсе выделяется красным цветом (текст + иконка).

Кастомные категории: пользователь может добавить любую категорию через Mini
App или команду в чате. При создании выбирается группа (Бизнес / Жизнь) и,
опционально, цвет.

3.2 Личные расходы (Жизнь)
Категория Описание
Аренда Квартира, офис, машиноместо
Автомобили Обслуживание, топливо, страховка
Путешествия Перелёты, отели, трансфер
Хобби Спорт, развлечения, увлечения
Дорогие покупки Ювелирка, брендовые вещи, техника
Люди Привязка расходов к имени человека — суммарный отчёт по каждому
Функция «Люди»: к любому расходу можно привязать имя. Отчёт показывает
суммарные затраты на каждого человека за выбранный период.

3.3 Система Loan (долги)
Дал в долг (Loan out): сумма, валюта, имя, дата, комментарий.
Должен сам (Loan in): аналогичные поля.
Статус долга: активный / частично погашен / закрыт.
Напоминания по долгам — настраиваемые алерты в Telegram.
4. Ввод данных пользователем
Пользователь вводит данные свободным текстом прямо в чат боту. Claude API
анализирует сообщение и извлекает структурированные данные.

Примеры (свободный формат):
> потратил 320 евро на аренду офиса
> пришло 5000 usdt на binance, зарплата
> дал в долг Максиму 1000 баксов
> добавь категорию "партнёрки" в бизнес
> /report неделя
> /balance
Список команд:
/add Внести расход или доход вручную
/balance Актуальные балансы всех кошельков и счетов
/report Отчёт за период (день / неделя / месяц)
/loan Управление долгами
/alert Настройка порогов уведомлений
/settings Открыть Mini App с настройками
/category Добавить / удалить / переименовать категорию
5. Мониторинг крипто-кошельков
Подключение только по публичному адресу (read-only). Приватные ключи не
требуются и не хранятся в системе.

Сеть Блокчейн API-источник
USDT TRC20 Tron (TRX) Tronscan API / TronGrid
USDT BEP20 BNB Chain BSCScan API
ETH ERC20 Ethereum Etherscan API
Количество кошельков на пользователя: до 5–7 адресов.
Частота опроса: настраивается (рекомендовано каждые 15–30 минут).
Алерт при входящей транзакции выше порога — мгновенное уведомление.
Данные транзакции: хэш, сумма, валюта, отправитель/получатель, время.
Исторические данные подгружаются при добавлении нового адреса.
6. Интеграции с внешними сервисами
6.1 Google Sheets
Двусторонняя синхронизация: агент читает данные из таблиц и записывает
обратно.
Мониторинг указанных таблиц с настраиваемой периодичностью.
Автоматически собирает расходы по проектам и обновляет категории.
Подключение через Google OAuth 2.0.
Пользователь задаёт ID таблицы и диапазон через Mini App.
6.2 Notion
Двусторонняя интеграция: чтение баз данных и запись отчётов.
Агент собирает финансовые данные со страниц Notion для расчётов.
Запись отчётов в Notion по запросу: /report → сохранить в Notion.
Подключение через Notion API (OAuth или Integration Token).
7. Отчёты и аналитика
7.1 Форматы отчётов
В чате (Telegram) Текстовое сообщение с ключевыми метриками и балансами
Инфографика График / диаграмма картинкой прямо в Telegram
Mini App дашборд Интерактивные графики, фильтры по периодам и категориям
PDF Полный финансовый отчёт за период по запросу
Notion Сохранение отчёта на страницу в Notion по запросу
7.2 Автоотчёты (периодичность настраивается)
Ежедневный: краткая сводка доходов/расходов за день.
Еженедельный: разбивка по категориям, динамика неделя к неделе.
Ежемесячный: полный отчёт с инфографикой и анализом трендов.
Дата и время отправки задаются в настройках Mini App.
7.3 Алерты
Входящая транзакция на кошелёк выше порогового значения.
Превышение бюджета по категории.
Напоминание о долге (Loan).
Пороговые значения задаются через /alert или Mini App.
8. Telegram Mini App — требования к экранам
Дашборд Сводные балансы, графики доходов/расходов, P&L по кошелькам
Транзакции Лента всех транзакций с фильтрами по дате, категории, источнику
Категории Добавить, переименовать, удалить, выбрать цвет категории
Кошельки Добавить/удалить адреса, история по каждому кошельку
Люди Список людей и расходов на них, управление долгами (Loan)
Интеграции Подключение Google Sheets, Notion, настройка периодичности
Настройки Периодичность отчётов, алерты, язык, часовой пояс
9. Безопасность
Приватные ключи и seed-фразы НЕ собираются и НЕ хранятся.
Крипто-кошельки подключаются только по публичному адресу (read-only).
OAuth 2.0 для Google и Notion — токены хранятся в зашифрованном виде.
Все API-ключи только на бэкенде, клиенту не передаются.
HTTPS / TLS для всех соединений.
Telegram User ID как идентификатор — регистрация не требуется.
10. Этапы разработки
Этап Срок Состав работ

MVP (этап 1) 3–4 нед. Telegram-бот + Claude API, ручной ввод, базовые категории, текстовые отчёты

Крипто (этап 2) 2–3 нед. Мониторинг TRC20 / BEP20 / ERC20, алерты, история транзакций

Интеграции (этап 3) 2–3 нед. Google Sheets двусторонняя, Notion двусторонняя

Mini App (этап 4) 3–4 нед. Дашборд, графики, управление категориями, кошельками, Loan-система

Полиш (этап 5) 1–2 нед. PDF-отчёты, инфографика в Telegram, финальное QA

11. Нефункциональные требования
Производительность Ответ бота — не более 3 сек. Отчёт — не более 10 сек.

Масштабируемость Архитектура поддерживает нескольких пользователей

Кастомизация Любая категория добавляется/изменяется без нового деплоя

Надёжность Логирование всех ошибок; graceful retry при сбоях API

Локализация Русский язык — основной. Заделы на мультиязычность
