## Стартовая точка (общая для всех сценариев)

Пользователь отправил голосовое "оборудование 100000". Транзакция создана и подтверждена. В чате:

```

│ 💸 100000 UAH                         │
│    оборудование                       │
│                                       │
│ 🛒 Оборудование                      │
│ 🕐 12:58, 23 мая                      │
│                                       │
│ 🏦 Монобанк · UAH                    │
│ Итог: 39844299 − 100000 = 39744299   │
│                                       │
│   [ ✏️ Изменить запись ]              │
└──────────────────────────────────────┘
```

> **Экран 0**. Кнопка = `ed:v:{txId}`.
> Redis: `midas:last_confirmed` = `msgId_A`.

### A-2. Пикер категорий

Экран 0 **удаляется**. "⏳ Распознаю..." **заменяется** пикером:

```
