# ADR-000: Requirements Reconciliation

**Статус:** ACCEPTED
**Дата:** 2026-05-04
**Участники:** Owner (User), AI Architect Agent

---

## Контекст

Проект Midas имеет два первичных документа-источника:
1. **Midaz_TZ v1** — исходное ТЗ заказчика
2. **Мастер-план Midas v2.0** — архитектурный план

При создании `project_config.md` (SSOT) были обнаружены **4 критических противоречия** и **8 пробелов** между документами. Данный ADR фиксирует все принятые решения по рекончиляции.

## Рассмотренные противоречия

### C-1: Язык бэкенда (Python vs Node.js)
- **ТЗ:** Python (FastAPI + aiogram)
- **Мастер-план:** Node.js
- **Решение:** → ADR-001. Node.js + TypeScript. Python допускается только как изолированный микросервис.

### C-2: Бот-фреймворк (aiogram vs grammY/telegraf)
- **ТЗ:** aiogram 3.x (Python-only)
- **Решение:** Следует из ADR-001. Используется Node.js бот-фреймворк (grammY / telegraf / raw webhook). Выбор конкретного — отложен до Phase 1.

### C-3: Очередь задач (Celery vs BullMQ)
- **ТЗ:** Celery + Redis (Python-only)
- **Решение:** Следует из ADR-001. Celery заменён на **BullMQ** (Redis-backed, Node.js-native). → ADR-014.

### C-4: Frontend (React/Vue vs React only)
- **ТЗ:** React / Vue (оба варианта)
- **Решение:** → ADR-002. React 19 only. Vue отклонён.

## Отклонённые опции

| Опция | Причина отклонения |
|---|---|
| n8n для оркестрации | Не подходит для основной продуктовой логики; недостаточная гибкость для сложных финансовых flows |
| Vue.js | Унификация стека; React имеет лучшую экосистему для TMA и Tremor UI |
| Celery | Python-only; несовместим с выбранным Node.js runtime |
| aiogram | Python-only; несовместим с выбранным Node.js runtime |

## Последствия

- `project_config.md` обновлён до версии 1.1 с учётом всех решений
- Все агенты обязаны использовать project_config.md v1.1+ как SSOT
- При обнаружении новых противоречий — создавать новый ADR, не молча переопределять
